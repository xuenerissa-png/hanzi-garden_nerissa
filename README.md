# 汉字小花园 🌷

给还不会拼音的小朋友玩的汉字键盘小游戏。跟着亮起的字母打出汉字，或者听声音找汉字；每完成一个字，就在花园里种一朵花。

## 玩法

- **打出字**：跟敲拼音提示，按空格或点按钮种下汉字，不要求先掌握拼音。
- **找汉字**：听读音，在三个汉字中点击选择，也支持数字键 1 / 2 / 3。
- **我的字库**：浏览三个分组，共 300 个字位（296 个不同汉字），点击进入练习。
- 每轮五朵花，没有计时、排名或扣分。
- 支持电脑键盘、手机触屏；花园位于练字区与键盘下方。
- 近期花朵和语速保存在当前浏览器，不发送到服务器。

默认名字使用虚构示例「小花朵 / 宝宝」。公开仓库不包含儿童真实姓名、私人截图或原项目提交历史。

## 本地运行

需要 Python 3，无需安装网页依赖：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

浏览器访问 http://127.0.0.1:8000 。

生成单文件 HTML：

```sh
python3 scripts/build_html.py
```

输出为 `hanzi-garden.html`。部分手机文件预览器和应用内浏览器不执行本地 HTML 脚本，这种情况下请通过 HTTP 网站打开。`127.0.0.1` 只指向当前设备，手机不能通过它访问另一台电脑。

## 声音

仓库默认使用设备提供的中文语音，效果因设备而异，部分设备可能需要网络。浏览器通常需要用户点击后才允许播放声音。

原自用版本的音频不随仓库分发。你可以使用自己拥有分发授权的 MP3：在 `dist/audio-map.js` 中配置「朗读文本 → 相对音频路径」，放入 `dist/audio/`。单文件构建工具会内嵌已配置的音频。

另提供可选的 Edge TTS 生成脚本，用 `zh-CN-XiaoxiaoNeural` 生成示例字库音频：

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-audio.txt
python scripts/generate_audio.py
python scripts/build_html.py
```

生成过程需要联网，会将脚本中的朗读文本发送至语音服务；请勿加入儿童个人信息。该服务由第三方提供，可能发生变化或不可用。使用及分发生成音频前，请自行确认服务条款和使用权限。MIT 许可证只适用于本仓库代码，不授予第三方声音或音频的权利。

## 字库与设计

字库由用户提供的识字挂图文字转录整理，只包含汉字、无声调拼音和少量读音提示，不包含挂图图片、商家插画或版式。分组不是官方课程标准，欢迎纠正读音和文本问题。多音字依当前词义提示练习；本项目不替代拼音或识字课程。

花朵由网页 SVG 绘制，无需图片资源。页面无广告、埋点、账号或后台。

## 结构

- `dist/`：可直接静态托管的网页、字库和音频映射。
- `scripts/build_html.py`：构建可携带的单文件 HTML。
- `scripts/generate_audio.py`：可选的配音生成工具。

提交改进时，请不要加入儿童真实姓名、照片、录音或其他个人信息。
